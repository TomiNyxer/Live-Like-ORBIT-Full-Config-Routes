# Live-Like-ORBIT-Full-Config-Routes



A ready-to-import ORBIT 2.0 config and matching route pack for 13 map variants. Both files are tuned together for quest traffic, looting, extraction and familiar PvP hotspots without using player-position convergence.

# Files

orbit-live-like-config.json

orbit-live-like-zones.orbitzones.json

ORBIT and its required dependencies are not included.

# Install

Install ORBIT, SAIN, Waypoints and BigBrain.

Start the SPT server and open https://127.0.0.1:6969/orbit.

Back up your current config under Overview → Backup & share.

Back up all maps under Zone editor → Share zone packs.

Import orbit-live-like-config.json under Overview → Backup & share, then select Save.

Import orbit-live-like-zones.orbitzones.json under Zone editor → Share zone packs → Import, then select Save.

Start a new raid.

# SAIN Setup

Use the SAIN Default preset and turn SAIN Extract Behavior off.

Recommended random personality chances:

Rat: 10

Wreckless: 5

SnappingTurtle: 5

Coward: 5

Chad: 5

Timmy: 3

GigaChad: 3

Other SAIN settings can remain unchanged.


# Compatibility

Made for SPT 4.1.5 and ORBIT 2.0.0. Do not combine it with QuestingBots, LootingBots, Phobos or separate AI limiter/culling mods. The preset does not change spawn loadouts, ammunition, bot counts or SAIN combat difficulty.
